# 005 - 优化缓存键生成策略

**日期**: 2024-01-01
**作者**: System

## 变更内容
1. **Context 核心调整**:
   - 修改 `FileSystemNode.mountSignature` 的生成逻辑。
   - 移除了 `mountPoint` 字段。

## 变更原因
- **解决缓存隔离问题**: 原有的签名包含挂载点路径，导致同一物理存储若被挂载到不同 VFS 路径（如 `/A` 和 `/B`），会生成不同的缓存 Key，导致缩略图等资源无法共享。
- **回归物理唯一性**: 现在的签名仅由 `type` (类型) + `localPath` (物理路径) + `config` (配置) 决定。这意味着只要指向同一个物理源，无论在 VFS 中挂载多少次，它们都共享同一套缓存，大幅节省空间并提高命中率。
